===========================
Employee Backend API Routes
===========================

Base URL
--------
http://localhost:3000


--------------------------------
Health Check
--------------------------------

GET /health

Description:
Checks whether the backend server is running.

Response:
{
    "status": "OK",
    "message": "Employee Backend Running"
}


--------------------------------
Authentication
--------------------------------

POST /auth/login

Description:
Authenticates a user and returns an access token and refresh token.

Request Body:
{
    "username": "admin",
    "password": "admin123"
}

Response:
{
    "accessToken": "...",
    "refreshToken": "...",
    "user": {
        "id": 1,
        "username": "admin",
        "role": "ADMIN"
    }
}


--------------------------------

POST /auth/refresh

Description:
Generates a new access token using a valid refresh token.

Request Body:
{
    "refreshToken": "..."
}

Response:
{
    "accessToken": "..."
}


--------------------------------

GET /auth/me

Description:
Returns the currently authenticated user.

Headers:
Authorization: Bearer <access_token>

Response:
{
    "id": 1,
    "username": "admin",
    "role": "ADMIN"
}


--------------------------------
Database (Temporary Debug Route)
--------------------------------

GET /db

Description:
Returns the complete contents of data/db.json.

Purpose:
Development and debugging only.
Should be removed before production.
